# Release notes — 0.1.1

Review-round housekeeping. The installation floor is corrected to Moodle
5.0 (the old value permitted untested 4.5 installs); the unjustified
XSS/spam risk flags on the add-block capability are dropped so role-audit
screens tell the truth; summaries stored with pre-encoded entities no
longer display double-escaped; and same-second resources render in a
stable order. A Dashboard Behat scenario now covers the block's primary
home.
